Meeting Recorder settings

Claude Code helper

Checking the helper...

    In Terminal, open the meeting-recorder folder and run npm run setup. It installs whisper.cpp, downloads the speech model and connects the helper to this extension. Then reload the extension on chrome://extensions.

    If the extension is loaded from another folder, run npm run setup -- --extension-id

    Whisper turns the speech into text on this Mac, and the audio never leaves it. Claude Code then translates the transcript into English when needed and writes the summary and action items, using the account you are signed in to with claude.

    Save folder

    Each meeting gets its own folder inside this one. Leave it empty to save in Downloads/Audio Recordings. Other folders need the helper.

    Microphone

    To record your own voice, tick Include my microphone in the popup before you start. The recorder runs in a hidden page that cannot ask for permission, so allow it here once.

    Summary and action items

    Any model name Claude Code accepts. It is also used to translate the transcript.
